How it works: "Slow down" moves a process into macOS's background resource band via taskpolicy -b — the scheduler throttles its CPU, disk I/O and timers, keeping the foreground snappy. It's fully reversible ("Restore" / taskpolicy -B) and needs no admin rights. CPU% is per core (100% = one full core). Browser rows expand to per-tab renderer processes, so a single heavy tab can be slowed without touching the rest of the browser. GPU shows device utilization (macOS doesn't expose per-process GPU without admin rights).
